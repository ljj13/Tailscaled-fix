# v1.102.5-dnsfix.2-webui.1

发布日期：2026-10-07 · 作者：FogPurification · arm64

本版将 Miuix WebUI 和 Android 默认设备名初始化整合进 main，保留
`feature/webui-miuix` 的完整提交历史及 merge commit。Tailscale 基础版本仍为
v1.102.5，继续使用已通过 Redmi Note 8 Pro 真机验收的 dnsfix.2 daemon 与
Android DNS helper 二进制。

## 更新内容

- 重新设计纯 HTML/CSS/JS WebUI：首页、设置、网络详情、DNS、路由、日志和关于。
  大标题、圆角分组卡片、Preference row、Switch、返回导航、Dialog/BottomSheet，
  支持系统浅色/深色主题及 safe-area；资源全部本地化。
- 保留 start/stop/restart、login/logout、状态、所有偏好设置、hostname、日志及
  selftest。高级 DNS 和路由字段集中到详情页，dnsfix.2 的诊断字段完整保留。
- WebUI bridge 使用已安装脚本的实际路径，保留自定义 socket，解决管理器 shell
  找不到 `tailscaled.service` 的问题；状态读取失败时显示明确提示并保留已有数据。
- 新增一次性 Android 默认设备名：仅 `Prefs.Hostname` 为空时，从用户设备名、
  marketname、model、device 依次取值，规范化后写入 hostname 偏好。
  已有名称保持原样，手工命名永久停止自动初始化；失败由启动/watchdog 重试。
  并发写入与进程被杀的情况有专门保护和回归测试。
- 提供本地 mock：Wi-Fi + FlClash、移动数据、NeedsLogin、DNS/路由失败和停止状态。
  README 和截图图库已更新；图片明确标记为桌面 mock。

## 升级与兼容

安装本版 ZIP 覆盖现有模块并重启。保留模块 ID `tailscaled`、Tailscale state、
登录身份、用户 settings/routes 和 hostname 保护标记，无需重新登录或删除节点。
模块版本更新为 `v1.102.5-dnsfix.2-webui.1`，versionCode 为 `110200503`。

保持 GOOS=linux reported OS、osrouter、fwmark、main default route、table 52、
Clash/Mihomo exemptions 和现有 DNS 发现实现。新增 hostname helper 独立于 DNS。
保留 arm64、无 Tailscale SSH、不能选择其他出口节点及模块管理更新的现有限制。
WebUI 需要支持模块 WebUI 的管理器或兼容宿主。

proxy exemptions、tailscale ping 与 kernel ping 全部通过。

新增真机验收记录。

shellcheck、Go vet；安装包复用的 daemon/DNS helper 字节与验收版本一致。
