# v1.102.5-dnsfix.2-webui.4

发布日期：2026-10-08 · FogPurification · arm64 · versionCode：110200506

## 更新内容

- 独立 Peers 页面：在线/离线分组、hostname、OS、Tailnet IPv4/IPv6、Direct/DERP/Unknown、endpoint/relay、最近活跃、Exit/Subnet 能力。支持只读 ping/RTT、复制和详情，不重复 Self。
- 脱敏诊断报告：统一采集与脱敏、预览/复制/保存；命令失败局部 unavailable，不泄漏 auth URL、token、私钥或 state。IP/hostname 保留用于排障。
- 网络变化通知加快 watchdog 同步：Wi-Fi→mobile 操作到 direct 的观测样本由17.862秒降至6.829秒；IPv4-only Wi-Fi 仍使用 DERP，慢建链样本未改善，不宣称所有切换均加速。保留15秒 fallback、自愈和 DERP fallback；不强制 direct，不更改流量选择算法。
- 修复 KernelSU light-only WebView 的 Android 系统深色主题跟随；统一主题 tokens，可选主题查询不阻塞服务命令。
- Release CI 显式执行 Peers、Report、Theme 单元套件，保留原命令、网络和浏览器断言。

## 验证范围

Redmi Note 8 Pro / KernelSU 真机通过 Peers、ping/RTT、报告预览/复制/原生保存、服务管理以及系统设置浅/深色热切换和重新打开。FlClash OFF/ON、DNS、Tailnet、IPv6 direct、切网与 IPv4-only Wi-Fi DERP fallback 保留既有验收。
